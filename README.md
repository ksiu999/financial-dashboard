# 📊 Financial Dashboard: Анализ денежных потоков и хозяйственной деятельности

## 📋 Описание проекта

Интерактивный дашборд для визуального анализа банковских операций компании за период 2022–2025 гг. Проект создан для демонстрации реальности хозяйственной деятельности, кредитной дисциплины и отсутствия признаков фиктивных сделок или вывода активов.

> ⚠️ **Важно:** Все данные в репозитории строго анонимизированы в учебных и демонстрационных целях. Названия контрагентов, ИНН и даты смещены с сохранением всех бизнес-пропорций, трендов и длительности отношений.

## 🎯 Цель и бизнес-задачи

Визуально и математически доказать:

1. **Реальность деятельности:** Ритмичность и непрерывность коммерческих операций.
2. **Кредитную дисциплину:** Целевое использование и возврат 97,5% кредитных средств за счет операционного потока.
3. **Отсутствие схем:** Сбалансированность внутренних переводов и мизерный объем возвратов.
4. **Долгосрочные отношения:** Длительность сотрудничества с ключевыми поставщиками (исключение разовых "технических" сделок).

## 📈 Структура дашборда

### Блок 1. Макро-баланс коммерции

- **Д1.1** — Диаграмма «Солнечные лучи» (Sunburst): иерархическая структура общих поступлений и списаний.

### Блок 2. Годовая динамика

- **Д2.1** — Коммерческие поступления по годам (сгруппированная гистограмма).
- **Д2.2** — Коммерческие списания по годам с детализацией статей расходов.

### Блок 3. Помесячный ритм

- **Д3.1 / Д3.2** — Линейные графики поступлений и списаний с маркерами, демонстрирующие равномерность бизнес-процессов.

### Блок 4. Кредитная дисциплина

- **Д4.1** — Диаграмма «Водопад» (Waterfall): кредитный цикл (Получено → Возвращено → Остаток).
- **Д4.2** — Сравнительная гистограмма получения и возврата кредитов по годам.

### Блок 5. Прозрачность операций

- **Д5.1** — Детализация обязательных платежей (налоги, ФОТ, комиссии).
- **Д5.2 / Д5.3** — Баланс возвратов и внутренних переводов (доказательство отсутствия чистого оттока).
- **Д5.4** — Детализация зарплатных выплат реальным физическим лицам.

### Блок 6. Длительность отношений

- **Д6.1** — Динамика расчетов с ключевыми поставщиками по месяцам (доказательство долгосрочного сотрудничества).

## 🛠 Технический стек и методология

- **Инструмент:** Microsoft Excel (без макросов в финальном файле, только формулы).
- **Обработка данных:** `СУММЕСЛИМН`, `ИНДЕКС` + `ПОИСКПОЗ`, `МИНЕС`/`МАКСЕС` для агрегации массивов >10 000 строк.
- **Анонимизация:** Собственный алгоритм маппинга уникальных ИНН с генерацией псевдонимов по категориям (Банк, Бюджет, Сотрудник, Контрагент) с сохранением последних 3 цифр маппинга для уникальности.
- **Визуализация:** Кастомные диаграммы Sunburst, Waterfall, Clustered Column, Line with Markers.

## 📁 Структура репозитория

- `data/processed/` — анонимизированный исходный файл с рабочими формулами.
- `dashboard/` — финальный PDF-документ и отдельные PNG-изображения диаграмм.
- `README.md` — документация проекта.

## 📜 Ключевые выводы

Совокупность факторов (длительность контрагентских связей, ритмичность платежей, исполнение обязательств перед сотрудниками/государством и добросовестный возврат кредитов) образует неопровержимую доказательственную базу реальности хозяйственной деятельности компании.
